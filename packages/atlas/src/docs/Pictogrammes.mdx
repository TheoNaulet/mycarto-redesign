# Pictogrammes

Jeu provisoire au trait (grille 24, trait 1,75). Un type d'objet = un pictogramme, le même partout. Cliquez pour copier `<McIcon name="…" />`.

Tailles : `sm` 14px, `md` 16px (défaut), `lg` 20px, `xl` 28px. Ajoutez `label` quand l'icône porte seule un sens.
