# Espacements, rayons, ombres

## Espacements (grille de 4px)

| Jeton | Valeur | Usage |
|---|---|---|
| `--space-1` | 4px | Écart icône/texte dans une puce |
| `--space-2` | 8px | Écart entre contrôles d'une barre |
| `--space-3` | 12px | Padding d'un nœud et d'un champ |
| `--space-4` | 16px | Padding d'un panneau, marge du canevas aux panneaux |
| `--space-5` | 24px | Pas de la trame du canevas, écart entre sections |
| `--space-6` | 32px | Padding d'une modale |
| `--space-7` | 48px | Marges des états vides |

## Rayons

| Jeton | Valeur | Usage |
|---|---|---|
| `--radius-xs` | 4px | Case à cocher, tuile d'icône de nœud |
| `--radius-sm` | 8px | Boutons, champs, nœuds |
| `--radius-md` | 12px | Menus, conteneurs, cartes |
| `--radius-lg` | 16px | Panneaux flottants, modales |
| `--radius-xl` | 24px | Post-its |
| `--radius-pill` | 999px | Puces, pilules de flux |

**L'onglet** : nœuds, conteneurs et indicateurs ont le coin haut-gauche carré, sous un onglet de 14 à 22px. Prévoir cet espace au-dessus de chaque élément.

## Ombres

Ce qui flotte au-dessus du canevas a une ombre, rien d'autre.

| Jeton | Usage |
|---|---|
| `--shadow-node` | Nœud au repos |
| `--shadow-hover` | Nœud ou tuile survolé |
| `--shadow-float` | Panneaux flottants |
| `--shadow-pop` | Menus, popovers, modales, toasts |

## Hauteurs

`--control-sm` 28px · `--control-md` 32px · `--control-lg` 40px · nœud `--node-w` 200 × `--node-h` 48 · panneau latéral `--panel-w` 320px.

## Mouvement

120ms (`--dur-fast`) pour les survols, 200ms (`--dur-base`) pour ouvrir un panneau, courbe `--ease-out`. Avec `prefers-reduced-motion`, aucune transition.
