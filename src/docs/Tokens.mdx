# Jetons

Tous les jetons sont des propriétés CSS déclarées sur `:root` dans `src/styles/base.css`. Un composant ne contient jamais de valeur de couleur, de taille ou d’espacement en dur.

## Couleurs

La palette vient du kit Elementor de myCarto. Le navy et le jaune portent la marque. Le reste sert au texte, aux filets et aux fonds.

## Typographie

Deux familles, toutes deux sous licence SIL Open Font et hébergées avec le site (Fontsource) :

- **Outfit** (`--font-display`) : titres, noms, boutons, pastilles et citations. C’est la voix de la marque.
- **Noto Sans** (`--font-text`) : tout ce qui se lit comme du texte courant.

Les grandes tailles suivent la largeur d’écran avec `clamp()`, il n’y a donc pas de palier dédié à la typographie.

| Jeton | Valeur | Usage |
|---|---|---|
| `--fs-3xl` | clamp(2.5rem → 4rem) | titre de page (h1) |
| `--fs-2xl` | clamp(2rem → 3.25rem) | titre de section (h2) |
| `--fs-xl` | clamp(1.5rem → 2rem) | sous-titre, ligne d’accroche |
| `--fs-l` | 1.3125rem | chapô, noms des listes |
| `--fs-m` | 1.0625rem | texte courant |
| `--fs-s` | 0.9375rem | lignes secondaires, boutons d’en-tête, pastilles |
| `--fs-xs` | 0.8125rem | mentions, métadonnées |

## Espacements

Une échelle unique, de 4 px à 112 px. Les sections respirent en `--space-8`, les grandes ouvertures en `--space-9`.

<div style={{ display: 'grid', gap: '0.6rem', margin: '1.5rem 0' }}>
  {[['--space-1', '0.25rem'], ['--space-2', '0.5rem'], ['--space-3', '0.75rem'], ['--space-4', '1rem'], ['--space-5', '1.5rem'], ['--space-6', '2rem'], ['--space-7', '3rem'], ['--space-8', '4.5rem'], ['--space-9', '7rem']].map(([name, value]) => (
    <div key={name} style={{ display: 'grid', gridTemplateColumns: '8rem 5rem 1fr', alignItems: 'center', gap: '1rem', fontSize: 14 }}>
      <code>{name}</code>
      <span>{value}</span>
      <span style={{ display: 'block', height: 14, width: value, background: '#262e6f', borderRadius: 3 }} />
    </div>
  ))}
</div>

La gouttière (`--gutter`, de 1rem à 2.5rem) et la largeur maximale (`--max`, 1400px) cadrent chaque `.wrap`.

## Formes

<div style={{ display: 'flex', flexWrap: 'wrap', gap: '1.5rem', margin: '1.5rem 0' }}>
  {[['--radius-panel', '20px', 'cadres, listes encadrées, visuels'], ['--radius-plate', '10px', 'plaques, vignettes'], ['--radius-pill', '999px', 'boutons, pastilles, onglets']].map(([name, value, use]) => (
    <div key={name} style={{ display: 'grid', gap: '0.5rem', fontSize: 14, maxWidth: '12rem' }}>
      <span style={{ display: 'block', width: '10rem', height: '5rem', border: '3px solid #262e6f', borderRadius: value, background: '#fac130' }} />
      <code>{name}</code>
      <span>{value}, {use}</span>
    </div>
  ))}
</div>

Le cadre (`--frame`, 3 px navy) entoure les listes encadrées, les visuels et les cartes. Il n’y a aucune ombre : la profondeur vient du contraste des fonds.

## Mouvement

| Jeton | Valeur | Usage |
|---|---|---|
| `--ease-out` | cubic-bezier(0.16, 1, 0.3, 1) | ce qui se pose : apparitions, menus, survols |
| `--ease-draw` | cubic-bezier(0.65, 0, 0.35, 1) | ce qui se trace, comme un stylo : rails, flux, routes |
| `--dur-draw` | 1.1s | la durée d’un tracé |
| `--stagger` | 90ms | le décalage entre deux éléments d’une même série |

Avec « réduire les animations », tout s’affiche directement : `v-draw` marque les tracés comme dessinés, et l’apparition au défilement ne masque rien.
